# Contributing Guide

Thank you for your interest in contributing to this project.

This repository is an experimental project exploring tools and workflows for interacting with Shelby decentralized storage.

## How to Contribute

You can contribute in several ways:

• improving documentation
• suggesting new features
• reporting bugs
• proposing workflow improvements
• contributing example scripts

## Development Workflow

1 fork the repository

2 create a new branch

git checkout -b feature/new-feature

3 make your changes

4 commit your changes

git commit -m "add new feature"

5 push to your fork

git push origin feature/new-feature

6 open a pull request

## Contribution Ideas

Examples of possible contributions:

• improve uploader scripts
• add CLI tools
• improve documentation
• create developer examples
• add automation scripts

## Code Style

Please keep the code simple and readable.

Prefer minimal dependencies and clear documentation.

## Reporting Issues

If you encounter any problems while using the tool, please open an issue describing:

• the problem
• expected behavior
• steps to reproduce
