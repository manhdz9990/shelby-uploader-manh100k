# Developer Notes

This document contains observations and notes while experimenting with Shelby decentralized storage.

## Experiment Goals

• understand file upload workflows
• test Shelby storage interactions
• explore automation possibilities

## Observations

Decentralized storage systems require careful handling of:

• network response times
• file size limitations
• retry mechanisms

These experiments aim to identify simple approaches for interacting with Shelby storage through lightweight scripts.

## Possible Improvements

Future improvements may include:

• better upload feedback
• error handling
• automated retries
• monitoring tools
