# Shelby Storage Uploader

A lightweight experimental tool for uploading files to the Shelby decentralized storage network.

This repository explores simple workflows for interacting with Shelby storage and aims to provide developers with a minimal example for testing decentralized file uploads.

---

## Overview

Decentralized storage systems are becoming an important part of Web3 infrastructure.
Shelby provides a distributed storage network designed for scalability and developer accessibility.

This project experiments with basic file upload workflows to better understand how developers can interact with Shelby storage through simple scripts and automation tools.

The main focus of this repository is learning, experimentation, and building lightweight developer tools.

---

• explore Shelby decentralized storage workflows

## Installation

Clone the repository:

```
git clone https://github.com/manhdz9990/shelby-uploader-manh100k
```

Enter the project folder:

```
cd shelby-uploader-manh100k
```

Install dependencies if required.

---

## Usage

Example upload workflow:

```
node uploader.js example.txt
```

This command uploads a file to the Shelby storage network using the experimental uploader script.
