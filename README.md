# Shelby Uploader Tool

A lightweight tool for uploading files to the Shelby decentralized storage network.

## Overview

This project is an experimental uploader designed to test how files can be stored and managed on the Shelby network.
The goal is to explore simple automation methods for interacting with Shelby storage APIs.

## Key Ideas

* Simplify the file upload process
* Provide a minimal script for developers testing Shelby
* Explore automation for repeated uploads

## Features

* File upload script
* Simple configuration
* Lightweight and easy to run

## My Contribution / Idea

In this project, I focused on exploring how Shelby storage could be used in simple workflows.
My idea is to build small tools that make decentralized storage easier to test for developers.

## Possible Future Improvements

* Add batch upload support
* Add upload progress indicator
* Build a CLI interface
* Integrate with Web3 wallets
* Add automatic retry for failed uploads
